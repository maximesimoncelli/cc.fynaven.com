# CC0.FYNAVEN.COM

The frontend for https://cc0.fynaven.com

# 1. Introduction

This is the repository of https://cc0.fynaven.com, which hosts graphical assets and illustrations for free, all released under a CC0 license.

# 2. Installation

## Requirements

- Node.js: "^24.9.0"
- Pnpm: "^11.1.1"

## Installation steps

We assume you use `pnpm`: https://pnpm.io/installation

```bash
# Optional, do this if you want to have pnpm execute the postinstall steps of binaries
pnpm approve-builds --all
# Required
pnpm i
pnpm postinstall
```
